# 记忆RPG游戏

一个基于Streamlit的网页端记忆卡牌游戏，结合了记忆匹配和RPG战斗元素。

## 游戏规则

### 基本玩法
- 游戏有20张牌，背面朝上按照4行×5列摆放
- 玩家初始生命值为100
- 每次可以翻开2张牌
- 如果点数**不同**：翻回去并轮到敌人行动
- 如果点数**相同**：
  - 移除这两张牌
  - 执行对应花色的效果
  - 继续翻牌，直到出现点数不同

### 卡牌效果
- **♠ 黑桃**：获得点数的护盾
- **♥ 红心**：回复点数的生命（不超过100上限）
- **♣ 梅花**：对敌人造成点数的伤害
- **♦ 方片**：揭示一张相同点数的牌的位置

### 敌人
1. **敌人1**：20生命，每回合对玩家造成10伤害
2. **敌人2**：40生命，每回合获得5护甲，对玩家造成10伤害
3. **敌人3**：60生命，每回合禁止一列卡牌操作，对玩家造成10伤害

### 胜利条件
连续击败三个敌人即可获得胜利！

## 安装和运行

### 方法1：本地运行（推荐）

1. **安装依赖**
```bash
pip install -r requirements.txt
```

2. **运行游戏**
```bash
streamlit run app.py
```

游戏会自动在浏览器中打开，默认地址为 `http://localhost:8501`

### 方法2：在线部署

您可以将此应用部署到以下平台：
- **Streamlit Cloud** (免费)：https://streamlit.io/cloud
- **Heroku**
- **AWS/Azure/GCP**

部署后即可通过网页链接访问游戏，无需本地安装。

### 快速开始

```bash
# 克隆或下载项目后
cd memoryRpg
pip install streamlit
streamlit run app.py
```

浏览器会自动打开游戏界面！
